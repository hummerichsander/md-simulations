# Simulation data root

This directory is the default **data root** for `md-simulations`. SLURM jobs
generated by `md-sim gen-slurm` default `MD_DATA_ROOT` to this folder, and
`md-sim run` resolves every input/output path against it.

Because trajectories are large (hundreds of GB to TB), **everything under
`data/` except this README is git-ignored.** Put the bytes here directly, or make
`data/` a symlink to bulk storage — the code only cares that `MD_DATA_ROOT`
resolves to a directory with this layout.

## Layout

Inputs live at stable, engine-relative paths referenced by the configs:

```
data/
  pdbs/                 # shared input structures (1UAO.pdb, 2JOF.pdb, ...)
  ala2/  ala3/  ala6/   # per-system inputs (ala2.pdb, ala6.pdb, ...)
  fs-peptide/           # fs-peptide.pdb, MARTINI gro/top, ...
  hexadecane/           # hexadecane_box.pdb, ...
  FreeSolv-0.51/        # gromacs_solvated/*.gro,*.top
  martini_v300/         # MARTINI3 itp include dir
```

Outputs are written to `<system>/<descriptor>/`, matching each config's
`output_subdir` (e.g. `cln/AMBER14_340K/`, `ala2/AMBER14_360K/`). Each run
directory contains `trajectory.dcd`, `energies.csv`, `forces.txt`, and
`final_structure.pdb` (OpenMM engines) or GROMACS `md.*` files (native engine).

## Pointing elsewhere

Override the default per run or per shell:

```bash
md-sim run configs/ala2.yaml --data-root /mnt/scratch/md
export MD_DATA_ROOT=/mnt/scratch/md
```
